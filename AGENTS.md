# Règles du projet

## Livraison d’un site testable

- Après chaque modification du site, fournir un site web fonctionnel que l’utilisateur peut tester immédiatement.
- Générer la version à jour, démarrer le serveur local si nécessaire et vérifier que le site est accessible et contient les modifications livrées.
- Toujours inclure le lien direct du site dans la réponse finale, avec une courte indication pour tester la modification si utile.
- Ne pas se limiter à fournir des commandes à exécuter : préparer et vérifier soi-même le site dans la mesure où l’environnement le permet. Si un obstacle empêche son fonctionnement, l’expliquer clairement.
- Pour ce projet, utiliser `npm run build` pour actualiser le site déjà servi, ou `npm start` pour le générer et démarrer le serveur. L’adresse locale habituelle est http://127.0.0.1:4173/.
